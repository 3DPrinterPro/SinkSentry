# SinkSentry
SinkSentry is an open-source dish detector built on a Raspberry Pi Zero 2 W. A camera mounted above the sink takes periodic photos, an on-device image classifier decides whether dishes have been left in the sink, and if they stay there past a set time the device buzzes until someone deals with them. A custom PCB designed in KiCad carries the buzzer, status LEDs, snooze button and sensor connections, so the whole thing plugs together cleanly instead of relying on a nest of jumper wires. Everything fits in a 3D-printed, splash-resistant enclosure, with the goal of a finished product you can actually leave running in a kitchen. Built for Hack Club Fallen.
